# nginx-static-poc

PoC de infraestructura: landing page estática de **Aceites del Aljarafe**
servida por un contenedor Nginx con Docker Compose.
Realizada por Guadalquivir Cloud Tech como paso previo a la migración
de la plataforma web del cliente.

## Contexto
Qué se valida con esta PoC: enrutamiento, carga de CSS, montaje de código
y análisis de logs. Módulo 0614 Despliegue de Aplicaciones Web, 2º DAW.
